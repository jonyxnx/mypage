    Notes on building without a framework

    Thoughts on keeping a personal site simple — one page, no build tools, no dependencies.

    There's something freeing about a single HTML file. No build step, no dependency updates, no bundler config to fight with — just open it in a browser and it works.

    For a personal site that doesn't need much dynamic behavior, that tradeoff is usually worth it.
